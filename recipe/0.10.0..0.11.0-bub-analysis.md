## Summary

This is a minor feature release (0.10.0 → 0.11.0) that adds support for pytest 9.x and Python 3.14, while dropping support for end-of-life Python versions 3.8 and 3.9. It also updates the Poetry configuration from the legacy `dev-dependencies` format to the newer `group.dev.dependencies` format. No breaking API changes are introduced.

## Dependency changes

- **pytest**: Upper bound relaxed to allow pytest 9.x (previously capped at <9)
- **Python 3.8 and 3.9**: No longer supported (dropped)
- **Python 3.14**: Now officially supported
- Minor lock file updates (Poetry upgraded from 1.5.1 to 2.3.2, resulting in updated lock format and removal of `astunparse` dev dependency)
